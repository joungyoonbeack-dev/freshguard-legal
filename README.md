# 프레시가드 약관·방침

유통기한 관리 앱 **프레시가드(FreshGuard)** 의 이용약관과 개인정보처리방침을 공개하는 저장소입니다.

- [개인정보처리방침](https://joungyoonbeack-dev.github.io/freshguard-legal/privacy.html)
- [이용약관](https://joungyoonbeack-dev.github.io/freshguard-legal/terms.html)

## ⚠️ 이 저장소의 HTML 은 직접 고치지 않는다

본문 원본은 개발 저장소에 있고, 이 파일들은 `scripts/build-legal-site.mjs` 가 생성한
결과물이다. 여기서 고치면 다음 생성 때 덮어써진다.

내용을 바꿀 때는 원본을 고치고 다시 생성해서 올린다.
앱 화면용 본문도 같이 고쳐야 한다 — 두 문서가 어긋나면 그 자체가 분쟁거리가 된다.
